##  What I'm Building

###  Open source

-  **[myjarbis](https://github.com/BraianTroncoso/myjarbis)** `open source · MIT` — Gives Claude Code persistent memory and structured workflows via MCP: one global server, per-project memory, code search and a CLI. Install once, use everywhere. *Not a prompt file. A second memory.* *(TypeScript + MCP + SQLite/FTS5)*

-  **[takeclass](https://github.com/BraianTroncoso/takeclass)** `open source · MIT` — Turns your day's git diff into an English-practice session: vocabulary, a reading script and drills from the code you actually shipped today. *(Claude Code skill + slash command)*

-  **[GesturePilot](https://github.com/BraianTroncoso/GesturePilot)** — Control Claude Code with hand gestures and voice from your webcam: MediaPipe hand-tracking + local Whisper + Piper TTS, no keyboard needed. *(Python + MediaPipe + Faster-Whisper)*

-  **[DevLog](https://github.com/BraianTroncoso/devlog)** — A living, bilingual logbook of applied AI: a 12-module *school* (Fundamentals → Production) plus a *Radar* feed that keeps every module current. *Not a course that ages.* *(Astro + Starlight + Mermaid)*

-  **[Apotheosis](https://github.com/BraianTroncoso/apotheosis)** — A consciousness laboratory inside a living world: an agent-based civilization that forages, specializes, raises families and — with no script at all — *invents faith*. Beneath it, one experiment: can a simulated mind come to suspect it is simulated? *Not a sandbox. A hypothesis test.* *(Three.js + Vue 3 + Web Workers + Ollama)*

-  **[aura-agent](https://github.com/BraianTroncoso/aura-agent)** `open source · MIT` — Your personal AI agent à la *Her*, living in Telegram: it reads your email, calendar and assigned PRs and writes your daily standup, all on a **local** model so your data never leaves your machine. *Not a chatbot. A second mind.* *(FastAPI + SQLite + Ollama + Telegram)*

-  **[hookforge](https://github.com/BraianTroncoso/hookforge)** `open source · MIT` — Turns any web app into a Linear/Vercel-style launch video from a config: the live UI inside a floating device on a branded stage, 3D camera, animated cursor, music and narration. *Never a screen-share with text on top.* *(Remotion + Playwright + ffmpeg)*

-  **[Data4Sales](https://github.com/BraianTroncoso/Data4Sales)** — A B2B multi-tenant platform that ingests a retailer's sales, exposes them in an operational dashboard and lets you act on its buyers: RFM segmentation, dirty-data handling and verifiable tenant isolation, measured at 255k orders. *Not a CRUD. A decision record* — 35 of them. *(Laravel + Vue 3 + Docker)*

-  **[collateral-health](https://github.com/BraianTroncoso/collateral-health)** `open source · MIT` — Given a Collateral Arrangement and the event that triggered the check, what is its health status? A pure, zero-dependency domain library: no clock, no randomness, no I/O — so an HTTP handler, a revaluation job and a replay of yesterday's book all get the same answer. *(TypeScript + Vitest)*

-  **[trainme](https://github.com/BraianTroncoso/trainme)** `open source · MIT` — A tiny CLI that preps you for an interview from your *persona* + a job posting: a 1-hour roadmap, likely Q&A and stack tips, no retyping. *Not a prompt you retype. A CLI that preps you in minutes.* *(Python + Rich + pypdf)*

-  **[GAME-JAM-FAD-CUYO-2022](https://github.com/BraianTroncoso/GAME-JAM-FAD-CUYO-2022)** — A complete game built in under 12 hours at a game jam. Ship or die.
